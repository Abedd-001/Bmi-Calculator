# Bmi-Calculator


A Python command-line program that calculates your Body Mass Index (BMI) from your height and weight and tells you which category you fall in.

## Usage

    python bmi.py

Enter your height in centimeters and your weight in kilograms.

## Categories

| BMI | Category |
|---|---|
| up to 16 | Severely under-weight |
| up to 18.5 | Under-weight |
| up to 25 | Healthy |
| up to 30 | Overweight |
| above 30 | Severely overweight |

## Built with

Python 3

This is a learning project, and the result is general information, not medical advice.
